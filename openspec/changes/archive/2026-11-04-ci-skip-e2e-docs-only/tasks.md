## Post-push verification (outside the archived checklist)

Verified locally against the real GitHub API before archiving (green base + docs-only diff: skip; green base + code: run; failed base + docs-only: run). On real CI, after the change is pushed with user authorization: the push that introduces the change runs E2E (its base has no pattern file yet); a later docs-only push on a green base must show `skip_e2e=true` in the step summary with E2E skipped and the job green; a docs-only push right after a code push must show `skip_e2e=false` naming the base check state.
