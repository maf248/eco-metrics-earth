## Why

The CO2 page answers "how much does one country emit over time" but not "how do countries compare
in a given year". A world choropleth map answers that at a glance, and a ranking table gives the
same comparison as indexable, keyboard-reachable text. The map library (ECharts) is already in
the app; a throwaway spike on real OWID data settled the open map questions (geometry source,
resolution, crosswalk, delivery) and the presentation (colors, controls, legend, year selection)
with the user.

## What Changes

- The CO2 page opens with a **world map of CO2 emissions per capita** for a selected year: five
  fixed classes on a yellow-to-red ramp, a "No data" class, a tooltip with per-capita and total
  emissions, zoom and drag, and a year slider that starts on the latest year.
- Below the map, a **ranking table** of every country for the selected year, collapsed under
  "View data table", highest per capita first by default and sortable by per capita or total in
  either order. Selecting a country on the map highlights its row,
  and selecting a row highlights the country on the map.
- Map controls: a vertical zoom-in / zoom-out / reset group on wider screens; on narrow screens
  pinch to zoom and a reset button that appears only after the view moved.
- Regions without a value are inert: no hover, no tooltip, no selection.
- **Geometry** is a committed, pre-projected (Equal Earth) static asset generated by a script from
  Natural Earth data (`world-atlas` 110m plus the small territories it lacks taken from 50m), with
  OWID entity codes resolved at generation time. The browser loads no geometry library.
- **Chart foundation:** a lazy map entry that registers the map and piecewise visual map only where
  used, a `map` skeleton variant, a sequential palette and a no-data token read by the theme
  adapter (options never name a color), and instance access on the chart wrapper.
- **Docs:** the design system records the sequential palette (now multi-hue, by decision), the
  no-data color, and the map conventions (including that the map box must take the map's own aspect
  ratio); the library catalogue records the closed map research; the roadmap drops the map item.

## Non-Goals

- No map on other categories yet; the components are generic so later categories can reuse them.
- No change to the BFF or the payload: the page already receives every country and year.
- No URL state for the year or the selected country (the page keeps one canonical URL).
- No sync between the map selection and the line chart's country selector below.
- No divergent palette.

## Capabilities

### New Capabilities

_None._

### Modified Capabilities

- `co2-emissions-page`: adds the world map, the ranking table and their skeleton.
- `chart-foundation`: adds the map entry, the sequential and no-data tokens, the map skeleton and
  instance access on the wrapper.
- `presentation-docs`: records the map conventions and the sequential palette decision.

## Impact

- **Web:** new components (`ChoroplethMap`, `MapLegend`, `YearSlider`, `Co2WorldMap`,
  `Co2RankingTable`), new libs (`co2MapOption`, `co2Ranking`, `worldGeometry`), chart foundation
  changes (`EChart`, `lazyChart`, `ChartSkeleton`, `chartTheme`, `chartTokens`, `globals.css`),
  the CO2 skeleton blocks, a static asset under `apps/web/public/geo/`.
- **Tooling:** `scripts/generate-world-geometry.mjs` and pinned root devDependencies used only by it
  (`world-atlas`, `topojson-client`, `d3-geo`, `d3-geo-projection`, `i18n-iso-countries`).
- **Docs:** `docs/design-system.md`, `docs/technical/libraries.md`, `ROADMAP.md`, `AGENTS.md`.
- **Weight:** about 50 KB gzipped of geometry, fetched once per visit and cached by the browser, plus
  the ECharts map and visual map modules in a chunk loaded only by pages with a map.
